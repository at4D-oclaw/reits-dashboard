# REITs Dashboard

实时中国公募 REITs 交易看板 — 自包含 HTML，浏览器直接打开。

## 核心特性

- ✅ **实时行情**：腾讯财经 API 实时价格、溢价率、NAV
- ✅ **数据纠偏**：自动修正 API 对 REITs 的 PB 和分红率失真
- ✅ **手动分派率**：招募书/季报数据手动填入，拒绝接口 bug
- ✅ **交易信号**：基于溢价率 + 分派率利差 + 52周分位三维判断
- ✅ **风险分层**：稳健 / 弹性 / 高波动 三列看板
- ✅ **零依赖**：单个 HTML 文件，无需服务器，双击打开

## 快速开始

```bash
# 1. 克隆
git clone https://github.com/<your-org>/reits-dashboard.git
cd reits-dashboard

# 2. 获取数据
python3 scripts/fetch_reits.py --output json > data.json

# 3. 用 data.json 中的数值更新 templates/dashboard.html，另存为 reits-dashboard.html

# 4. 打开
open reits-dashboard.html
```

## 数据质量说明

### 行情接口的已知陷阱

| 字段 | 接口值 | 实际值 | 处理方式 |
|------|--------|--------|----------|
| 溢价率 | 腾讯 API | ✅ 准确 | 直接使用 |
| NAV | 腾讯 API | ✅ 准确 | 直接使用 |
| PB | 腾讯 API 0.32 | 真实 PB ≈ 1.01 | **忽略接口，手动计算** |
| 年化分红 | 腾讯 API 55.5% | 实际 ~6.8% | **忽略接口，手动填入** |

### 手动计算规则

```python
# 真实 PB（基金层面）
real_pb = price / nav

# 实际分派率（必须手动填入招募书数据）
dividend_yield = per_share_annual_distribution / price * 100%

# 利差
spread = dividend_yield - risk_free_rate  # 通常用10Y国债
```

### 数据来源分工

| 指标 | 来源 | 更新频率 |
|------|------|----------|
| 现价、溢价率、NAV | 腾讯财经实时 API | 实时 |
| 分派率 | 招募说明书 + 季度报告 | 每季度 |
| 52周区间 | 腾讯财经 API | 实时 |
| 交易信号 | 基于上述手动计算 | 实时 |

## 交易信号规则

| 条件 | 信号 | 动作 |
|------|------|------|
| 溢价 < 5% + 利差 > 国债 + 2% + 长端见顶 | ✅ 买入 | 建仓 |
| 溢价 < 15% + 季报分红不超预期 | ⏳ 持有 | 继续持有 |
| 溢价 > 25% | ⚠️ 警告 | 考虑减仓 |
| 溢价 > 34% + 单场集中 | ❌ 回避 | 不介入 |
